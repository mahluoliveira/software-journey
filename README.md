# 🚀 Software Journey

> *"Transformando café em código e bugs em aprendizado, um commit por vez."* ☕✨

Bem-vindo(a) ao meu diário de bordo no universo do desenvolvimento de software! 🛸

Este repositório é o meu laboratório pessoal — o cantinho sagrado onde registro minha evolução, celebro cada vitória contra os algoritmos, anoto insights de leituras técnicas e dou vida a projetos pessoais.

Se você procura códigos perfeitos... talvez esbarre primeiro em alguns `print("socorro funcionou")`, mas faz parte da beleza do processo! 😂

## 🗺️ O Mapa da Mina

A casa está dividida da seguinte forma:

```text
software-journey/
│
├── 🏋️ Exercícios/     # Treinos de lógica, Beecrowd, LeetCode e afins
├── 📚 Livros/         # Anotações, resumos e lições dos livros estudados
└── 🛠️ Projetos/       # Ideias que saíram do papel e viraram código
```

### 🏋️ [Exercícios](./Exercícios/)
Onde meus neurônios pegam peso para valer.
- Desafios de lógica, algoritmos e estruturas de dados (como os desafios do **Beecrowd**).
- Cada status `Accepted` é comemorado como gol em final de campeonato! 🏆

### 📚 [Livros](./Livros/)
A biblioteca de sobrevivência da mente dev.
- Resumos, anotações de leitura e reflexões práticas sobre os livros técnicos que estou devorando.
- Boas práticas, conceitos fundamentais e teorias destrinchadas.

### 🛠️ [Projetos](./Projetos/)
Onde a teoria encontra a realidade (e às vezes sai faísca).
- Experimentos práticos, protótipos e projetos pessoais.
- Soluções criadas para resolver dores reais ou simplesmente para testar tecnologias novas.

## 🧭 Leis Fundamentais deste Repositório

1. **Se funcionou de primeira:** desconfie. Muito provavelmente algo passou batido.
2. **`print()` como ferramenta de debug:** ciência pura, respeite a tradição.
3. **O código de ontem:** sempre parecerá ter sido escrito por outra pessoa há 10 anos.
4. **Constância > Perfeição:** o importante é codar um pouco todo santo dia e nunca parar de aprender! 📈
